📊 技术实现

1. CSS宽高比属性（aspect-ratio）

.gallery-image {
    aspect-ratio: 4/3;
}

作用：定义元素的宽高比为4:3。宽度变化时，高度自动按比例调整。

2. 绝对定位填充容器

.portfolio-image {
    position: absolute;
    top: 0; left: 0;
    width: 100%; height: 100%;
    object-fit: contain;
}

作用：让图片和占位符完全填充4:3的容器，保持比例。

3. 响应式宽度限制

.gallery-item {
    flex: 0 0 min(300px, 90vw);
}

@media (max-width: 768px) {
    .gallery-item {
        flex: 0 0 min(250px, 85vw);
    }
}

作用：控制图框宽度，与4:3高度比例配合，实现完美响应式。
