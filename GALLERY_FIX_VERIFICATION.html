✅ 后期选集图框尺寸Bug修复完成

修复状态：已应用
修复成功！ 后期选集图框尺寸bug已修复。现在图框在不同屏幕尺寸下都能正确显示，不会超出屏幕边界。
修复内容

修复了CSS中.gallery-item类的宽度设置问题：

修复前（有问题）
/* 桌面端 */
.gallery-item {
    flex: 0 0 300px;
}

/* 移动端 */
@media (max-width: 768px) {
    .gallery-item {
        flex: 0 0 250px;
    }
}

问题：固定像素宽度在小屏幕上会导致图框过大，超出屏幕边界。

修复后（已解决）
/* 桌面端 */
.gallery-item {
    flex: 0 0 min(300px, 90vw);
}

/* 移动端 */
@media (max-width: 768px) {
    .gallery-item {
        flex: 0 0 min(250px, 85vw);
    }
}

解决方案：使用min()函数，确保图框宽度不会超过屏幕宽度的百分比。

技术细节

使用的CSS函数：min(300px, 90vw)

  • min()：返回两个值中较小的一个
  • 300px：最大宽度限制
  • 90vw：视口宽度的90%
  • 效果：当屏幕宽度小于333px时，使用90vw；否则使用300px

响应式断点：768px

  • ≥768px：使用 min(300px, 90vw)
  • <768px：使用 min(250px, 85vw)
  • 确保移动端有更紧凑的布局
