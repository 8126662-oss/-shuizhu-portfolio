2. 修改前后对比

之前（强制1:2比例）

  • ❌ aspect-ratio: 1 / 2
  • ❌ 固定竖屏比例
  • ❌ 图片可能被裁剪
  • ❌ 文字可能不完整
  • ❌ object-fit: cover

现在（自适应高度）

  • ✅ height: auto
  • ✅ 根据图片比例自适应
  • ✅ 图片完整显示
  • ✅ 文字100%可见
  • ✅ object-fit: contain
  • ✅ background: rgba(0,0,0,0.3)
  • ✅ max-height: 700px

3. CSS代码

/* 课程大纲第一个展示框 - PS入门篇（自适应高度） */
.single-image-display.outline-display {
    position: relative;
    border-radius: 12px;
    overflow: hidden;
    width: 100%;
    height: auto; /* 根据图片比例自适应高度 */
    max-height: 700px !important; /* 防止图片过长 */
    border: 1px solid rgba(255, 255, 255, 0.1);
    background: rgba(0, 0, 0, 0.3); /* 半透明黑色背景，防止留白 */
    display: flex;
    justify-content: center;
    align-items: center;
}

/* 自适应图片样式 - 完整显示图片内容 */
.single-image-display .full-image {
    width: 100%;
    height: auto; /* 根据原始比例自适应 */
    max-height: 700px; /* 限制最大高度 */
    object-fit: contain; /* 完整显示图片，不被裁剪 */
    object-position: center;
}
