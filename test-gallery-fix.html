问题分析：固定300px宽度在小屏幕上会导致图框过大，超出屏幕边界。
修复方案1：自适应宽度（min函数）
.gallery-item {
    flex: 0 0 min(300px, 90vw); /* 修复：自适应宽度 */
    transition: all 0.3s ease;
}

修复方案3：媒体查询响应式
.gallery-item {
    flex: 0 0 300px;
    transition: all 0.3s ease;
}

@media (max-width: 768px) {
    .gallery-item {
        flex: 0 0 min(250px, 85vw);
