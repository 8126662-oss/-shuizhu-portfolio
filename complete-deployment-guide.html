🎨 水墨竹作品集部署指南

只需3步，将你的网站部署到GitHub Pages

1 创建GitHub仓库

点击下方链接创建新仓库：

👉 点击打开 GitHub 创建仓库页面

填写以下信息：

  • Repository name: shuizhu-portfolio（建议）
  • Description: 水墨竹作品集网站（可选）
  • Public: ✅ 选择公开
  • 不要勾选：
    • ☐ Add a README file
    • ☐ Add .gitignore
    • ☐ Choose a license
注意： 创建仓库后，不要关闭页面！GitHub会显示快速设置命令，你需要复制这些命令。
✅ 完成标志： 看到GitHub提供的命令，类似这样：
git remote add origin https://github.com/8126662-oss/shuizhu-portfolio.git
git branch -M main
git push -u origin main
2 运行部署脚本

打开项目文件夹，运行部署脚本：

cd "C:\Users\86152\Documents\trae_projects\box1"

然后双击运行：deploy-all.bat

脚本会做什么：
  • ✅ 检查Git配置（已配置：8126662-oss / 8126662@mail.com）
  • ✅ 初始化Git仓库
  • ✅ 添加所有文件到暂存区
  • ✅ 提交更改到本地仓库
  • 🔄 然后会提示你输入GitHub仓库URL

当脚本提示时，粘贴GitHub提供的命令：

git remote add origin https://github.com/8126662-oss/shuizhu-portfolio.git
git branch -M main
git push -u origin main
3 启用GitHub Pages

代码推送完成后，启用GitHub Pages：

👉 点击打开 GitHub Pages 设置页面

设置步骤：

  1. 在 Source 部分，选择：Deploy from a branch
  2. 在 Branch 部分，选择：main 分支
  3. 文件夹选择：/ (root)
  4. 点击 Save 按钮
✅ 完成标志： 看到绿色提示 "Your site is published at ..."
注意： GitHub Pages 可能需要1-2分钟来构建和发布你的网站。

🎉 你的网站将在这里访问：

https://8126662-oss.github.io/shuizhu-portfolio/

部署完成后，点击上方链接即可访问你的作品集网站！
